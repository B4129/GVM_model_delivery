# GrinekoVideoMaker model distribution

Public distribution of SET 17 and SET 18 models for GrinekoVideoMaker.

Models and textures are copyright Riot Games. Sources: [CommunityDragon](https://raw.communitydragon.org/) and [Khada](https://modelviewer.lol/). This project is not affiliated with or endorsed by Riot Games.

The app reads `v1/manifest.json` and loads the selected model from the content-addressed files in `v1/objects/`. Shared content between the live and PBE channels is stored once. Only model distribution data is published here; no credentials or app code are included.
